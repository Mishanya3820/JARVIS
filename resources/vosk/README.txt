Vosk Russian STT

1. Download the official Vosk Russian small model:
   https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip

2. Extract it so this folder contains:
   resources/vosk/vosk-model-small-ru-0.22/

3. Install the Python package:
   python -m pip install vosk

The model is intentionally not stored in Git because it is a binary model.
